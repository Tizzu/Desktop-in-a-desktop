# Privacy policy – Desktop in a Desktop

_Last updated: 2026-10-30_

Desktop in a Desktop is a browser extension that replaces the new tab page with a desk of widgets.

**It collects nothing.** The extension has no server, no account, no analytics and no network access of its own. Nothing you write or set up ever leaves your computer through the extension.

## What is stored, and where

Your spaces, widgets (including their text, drawings and images) and settings are stored locally in your browser profile (IndexedDB, plus a small backup in the page's local storage and the browser's extension storage for the language). Uninstalling the extension or clearing the browser's data deletes them. The data is not synced between computers.

If you use *Export*, the file or text is created on your computer and goes only where you choose to send it.

## Permissions

- `storage` – save your data and your language choice.
- `alarms` and `notifications` – let timers and reminders ring, with a notification, even when the tab is closed.
- `search` – the search widget sends your query to your browser's default search engine, exactly as typing in the address bar would. If the browser cannot run the search itself, the query is opened on DuckDuckGo (duckduckgo.com) instead.

The extension never reads or changes the websites you visit. Links you add to the Quick links widget are opened in a new tab only when you click them.

## Limited Use

The extension does not collect or transmit user data, so it does not sell it, use it for advertising or credit decisions, or let anyone read it. Its use of any data stays within the Chrome Web Store User Data Policy, including the Limited Use requirements.
